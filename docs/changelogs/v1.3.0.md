# VCPMobile v1.3.0 更新日志

**发布日期**: 2026-02-23

## 一、功能变更

### 新增功能
- **长按音量下键录音发送**: 息屏或任意界面下，长按音量下键 0.6 秒开始录音，松开后自动发送给 AI Agent 并写入 VCPChat 话题。采用"对讲机"模式，按住说话，松开发送，体验直觉自然。录音文件自动转 base64 通过多模态 API 发送，支持 Gemini 等支持音频输入的模型。

### 修复问题
- 无

## 二、技术实现

### 架构变更
- 新增 `VoiceRecorderService` 前台服务，负责录音、调用 AI API、写入话题的完整流程
- 扩展 `VolumeKeyService` 辅助功能服务，添加音量下键长按/松开手势检测
- 扩展 `VCPApiHelper` 工具类，添加 `chatAudio()` 多模态音频发送方法

### 代码变更
- **新建文件**:
  - `android/app/src/main/java/com/vcp/vcpmobile/VoiceRecorderService.java` (242 行) — 前台服务录音，MediaRecorder 录制 AAC/M4A 格式，录音完成后自动调 AI API + 写入话题
  
- **修改文件**:
  - `android/app/src/main/java/com/vcp/vcpmobile/VolumeKeyService.java` — 添加音量下键处理逻辑（长按开始录音，松开停止并发送），保持音量上键原有功能（双击截图、长按剪贴板）不变
  - `android/app/src/main/java/com/vcp/vcpmobile/VCPApiHelper.java` — 添加 `chatAudio()` 方法，支持发送 base64 音频 + 文本到多模态 API，添加 `mimeTypeToFormat()` MIME 类型转换
  - `android/app/src/main/AndroidManifest.xml` — 添加 `FOREGROUND_SERVICE_MICROPHONE` 权限，声明 `VoiceRecorderService` 服务（foregroundServiceType="microphone"）

### 手势设计
- **音量上键**（保持不变）:
  - 单击 → 正常提高音量
  - 双击 → 发送截图给 AI
  - 长按 → 发送剪贴板给 AI
  
- **音量下键**（新增）:
  - 单击 → 正常降低音量
  - **长按 → 开始录音（按住期间持续录制）**
  - **松开 → 停止录音并发送给 AI**

### 录音流程
1. 长按音量下键 0.6 秒 → `VolumeKeyService` 检测到长按 → 启动 `VoiceRecorderService` (ACTION_START_RECORDING)
2. `VoiceRecorderService` 启动前台通知 → 使用 `MediaRecorder` 开始录音（AAC 编码，44.1kHz，128kbps）
3. 松开音量下键 → `VolumeKeyService` 发送停止指令 → `VoiceRecorderService` (ACTION_STOP_AND_SEND)
4. 停止录音 → 读取音频文件为 base64 → 调用 `VCPApiHelper.chatAudio()` 发送给 AI
5. AI 回复后 → 调用 `appendToAgentHistory()` 写入 VCPChat 话题（话题名格式：🎤 语音 MM-dd HH:mm）
6. 更新通知栏显示 AI 回复预览 → 8 秒后自动关闭服务并删除临时音频文件

### 容错处理
- 录音时长 < 1KB（约 0.1 秒）视为误触，自动丢弃
- 支持 API 调用失败重试（继承 `VCPApiHelper` 的重试机制）
- 临时音频文件存储在 `getCacheDir()`，服务销毁时自动清理

## 三、依赖项目变更

### VCPToolBox 需要的改动
**本次无需改动** — 录音功能完全在移动端实现，复用现有的 `/v1/chat/completions` API 和 `/admin_api/agents/vcpchat-append-history` 接口。

### VCPChat 需要的改动
**本次无需改动** — 录音消息写入话题后，VCPChat 桌面端可正常查看（显示为"[语音消息] + 预设提示词"）。

## 四、使用说明

### 前置条件
1. 已开启辅助功能服务（设置 → 辅助功能 → VCP 音量键服务）
2. 已授予录音权限（首次使用时系统会弹窗请求）
3. 已在 VCPMobile 设置中配置好 API 参数（baseUrl、apiKey、model、adminUsername、adminPassword、agentDirId）
4. 使用的 AI 模型支持音频输入（如 Gemini 2.0 Flash、GPT-4o 等）

### 配置项
在 VCPMobile 设置中可配置：
- `presetVoiceMessage`（默认："请听取并回复这段语音"） — 发送给 AI 的文本提示

### 使用步骤
1. 息屏或任意界面下，长按音量下键约 0.6 秒
2. 看到 Toast "VCP: 🎤 开始录音..." 和通知栏提示
3. 持续按住说话（可以说任意时长）
4. 松开音量下键
5. 通知栏显示"正在发送给 AI..." → "正在等待 AI 回复..." → "✅ AI: [回复预览]"
6. 打开 VCPMobile 或 VCPChat 查看完整对话（话题名：🎤 语音 MM-dd HH:mm）

### 注意事项
- 录音格式为 AAC/M4A，部分模型可能不支持（Gemini 支持）
- 录音过短（< 0.1 秒）会被自动丢弃
- 录音期间通知栏会显示"正在录音..."，符合 Android 前台服务规范
- 录音文件仅临时存储，发送完成后自动删除，不占用存储空间

## 五、兼容性

- **最低 Android 版本**: Android 7.0 (API 24)
- **推荐 Android 版本**: Android 12+ (API 31+)
- **已测试设备**: OnePlus 13 (Android 16, ColorOS 16.0.3)
- **已测试模型**: Gemini 2.0 Flash (支持音频输入)

## 六、已知限制

- 音频输入功能依赖 AI 模型支持，不支持音频的模型会返回错误
- 部分国产 ROM（如 MIUI、ColorOS）可能在息屏时限制前台服务，导致录音中断（已在 ColorOS 16 测试通过）
- 录音质量受环境噪音影响，建议在安静环境使用或使用蓝牙耳机
