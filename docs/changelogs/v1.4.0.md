# VCPMobile v1.4.0 更新日志

**发布日期**: 2026-02-23

## 一、功能变更

### 新增功能

- **调试日志查看器**：设置页面新增"调试日志"入口，可查看应用运行日志、一键复制日志内容、清空日志。方便用户诊断连接问题和反馈 Bug。
- **连接状态诊断面板**：点击 Agent 名称旁的状态指示点，弹出连接诊断面板，显示服务器地址、HTTP API 状态、WebSocket 推送状态、同步状态、当前 Agent 信息，支持一键"测试连接"。
- **全链路日志记录**：API 请求/响应、WebSocket 连接/断开/推送、ChatSync 同步操作、Agent 拉取等关键路径均记录到调试日志，便于问题排查。
- **VCPMobile 适配文档**：新增 `docs/VCPMobile_Adaptation_Guide.md`，完整记录 VCPToolBox/VCPChat 为适配 VCPMobile 而新增的文件、12 个 API 端点的调用方式和参数说明。

### 改进

- WebSocket 推送模块日志从 `console.log` 迁移到统一的 `debugLogger`，日志可在 UI 中查看
- Agent 服务、ChatSync 同步模块同步迁移到统一日志系统

## 二、技术实现

### 架构变更

- 新增 `src/utils/debugLogger.js` 模块，提供统一的日志管理（分级记录、500 条缓存、系统信息导出）
- 所有服务模块（vcpApi、chatSync、agentService、vcpPush）统一使用 debugLogger

### 代码变更

| 文件 | 改动摘要 |
|------|---------|
| `src/utils/debugLogger.js` | **新增** — DebugLogger 类，支持 info/warn/error 分级、格式化输出、系统信息采集、日志导出 |
| `src/App.vue` | 新增日志查看器 UI（设置页面入口 + 全屏日志面板）、连接诊断面板、pushStatusText 计算属性、runConnectionTest 函数、onMounted 启动日志 |
| `src/services/vcpApi.js` | 导入 logger，在 fetchModels/streamChat/interruptChat 中添加请求/响应日志 |
| `src/services/chatSync.js` | 导入 logger，替换内部 log/warn 为 logger 调用，checkSyncStatus 添加详细日志 |
| `src/services/agentService.js` | 导入 logger，替换内部 log/warn，fetchAgentList 添加请求日志 |
| `src/services/vcpPush.js` | 导入 logger，所有 console.log/warn/error 替换为 logger 调用 |
| `src/style.css` | 新增连接诊断面板样式（.connection-diag-*）和调试日志查看器样式（.debug-log-*） |
| `docs/VCPMobile_Adaptation_Guide.md` | **新增** — VCPToolBox/VCPChat 适配指南（PR 清单、API 文档、部署说明） |

## 三、依赖项目变更

### 无需改动

本次更新仅涉及 VCPMobile 前端代码，不需要改动 VCPToolBox 或 VCPChat。
