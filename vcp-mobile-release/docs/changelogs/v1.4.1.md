# VCPMobile v1.4.1 更新日志

**发布日期**: 2026-02-23

## 一、功能变更

### 新增功能

- **VCPChat 兼容按钮点击**：AI 输出的 `<button>` 标签现在可以直接点击，点击后自动发送 `[[点击按钮:文字]]` 给 AI，与 VCPChat 桌面端行为一致。支持 `data-send` 属性指定发送内容。
- **onclick 按钮支持**：AI 输出的 `onclick="input('文字')"` 按钮可在主页面安全执行，支持 `input()`、`alert()`、`confirm()`、`prompt()` 四种函数。
- **按钮视觉反馈**：点击按钮后自动变灰并显示 ✓，防止重复点击。

### 修复问题

- **修复按钮无法点击**：之前 `<div id="vcp-root">` 内带 `onclick` 的按钮会错误触发 iframe 沙箱渲染，导致按钮被隔离在 iframe 中无法响应点击。现在仅 `<script>` 标签才触发 iframe 沙箱，`onclick` 按钮在主页面通过事件委托处理。

## 二、技术实现

### 架构变更

- 按钮渲染路径分离：`<script>` → iframe 沙箱（完整 JS 执行）；`onclick` → 主页面事件委托（安全沙箱执行）
- DOMPurify 后处理：`onclick` 属性转换为 `data-vcp-click` 数据属性，避免 CSP 限制
- 全局 click 事件委托同时处理两种按钮类型

### 代码变更

| 文件 | 改动摘要 |
|------|---------|
| `src/utils/vcpRichSandbox.js` | `needsSandbox()` 仅对 `<script>` 标签返回 true，不再对 `onclick` 触发沙箱 |
| `src/utils/htmlAutoComplete.js` | `hasExecutableScript()` 同步修改，仅检测 `<script>` 标签 |
| `src/utils/messageRenderer.js` | DOMPurify 添加 `data-send` 属性允许；新增 `onclick` → `data-vcp-click` 后处理转换 |
| `src/App.vue` | 新增全局按钮事件委托：VCPChat 风格 `<button>` 发送 `[[点击按钮:文字]]`；`data-vcp-click` 安全执行 `input()/alert()/confirm()` |

## 三、依赖项目变更

### 无需改动

本次更新仅涉及 VCPMobile 前端渲染逻辑，不需要改动 VCPToolBox 或 VCPChat。
